# **Pengajuan Cuti**

Untuk pengajuan cuti, lakukan langkah-langkah berikut.

Login ke [iGracias](https://igracias.telkomuniversity.ac.id/index.php).

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/cuti1.png)

Open **Dashboard** dan cari **Registrasi** dan pilih **Pengajuan Cuti**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/cuti2.png)

Klik **Input Mahasiswa Cuti**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/cuti3.png)

Isi **Form Pengajuan Cuti** dan **Simpan**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/cuti4.png)
