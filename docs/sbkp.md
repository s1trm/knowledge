# **Surat Bebas Kewajiban Perpustakaan (SBKP)**

Sedang mengurus Surat Bebas Kewajiban Perpustakaan (SBKP)?

Pastikan semua tahapannya sudah kamu lewati dengan benar, ya. Mulai dari

- unggah dokumen karya akhir,
- cek status persetujuan, -
- memastikan tidak ada pinjaman atau denda,
- hingga proses verifikasi oleh Open Library,

Semuanya perlu dicek satu per satu agar prosesmu lancar tanpa kendala ([sumber](https://www.instagram.com/p/DTRa-FICWAA/?utm_source=ig_web_copy_link&igsh=NTc4MTIwNjQ2YQ==)).
