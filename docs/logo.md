### CSS Variables

```css
:root {
  --trm-gold-base:  #BC9601; /* Primary — matches logo exactly */
  --trm-gold-light: #E0C24A; /* Light gold — highlights, hover */
  --trm-gold-tint:  #F5EBC6; /* Very light tint — subtle backgrounds */
  --trm-gold-dark:  #8A6E01; /* Darker gold — pressed/active states */
  --trm-gold-deep:  #5C4900; /* Deep gold/brown — text on light gold */
  --trm-white:      #FFFFFF; /* Background / negative space */
}
```
