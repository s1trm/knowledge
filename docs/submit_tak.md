# **Submit TAK**

Login ke [aplikasi web TAK](https://situ-kem.telkomuniversity.ac.id/tak/auth/login).

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/submit_tak_1.png)

Pilih di kiri, menu **Masukan TAK**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/submit_tak_2.png)

Isi **Formulir Masukan**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/submit_tak_3.png)

Setelah mengisi, centang kotak yang menyatakan data sesuai lalu klik **Simpan**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/submit_tak_4.png)
