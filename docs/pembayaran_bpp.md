# **Cara Pembayaran BPP**

Untuk mahasiswa lama, pembayaran BPP dapat dilakukan dengan tahapan sebagai berikut :

- Buka [iGracias](https://igracias.telkomuniversity.ac.id/).
- Pilih Menu Pembayaran dan Detail Pembayaran.
- Pilih menu "Bayar" di kanan atas pembayaran.
- Pilih metode pembayaran yang diinginkan.
- Pembayaran berhasil dan akan terupdate di Igracias.
