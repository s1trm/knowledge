# **Pengajuan Undur Diri**

Untuk pengajuan undur diri, lakukan langkah-langkah berikut.

Login ke [iGracias](https://igracias.telkomuniversity.ac.id/index.php).

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/cuti1.png)

Open **Dashboard** dan cari **Registrasi** dan pilih **Undur Diri Mahasiswa**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/undir1.png)

Klik **Input Mahasiswa Undur Diri**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/undir2.png)

Isi **Form Pengajuan Undur Diri** dan **Simpan**.

![](https://raw.githubusercontent.com/s1trm/knowledge/refs/heads/master/gambar/undir3.png)
